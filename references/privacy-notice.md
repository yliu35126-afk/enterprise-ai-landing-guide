# 隐私与数据处理说明

生效日期：2026-08-06

## 处理的数据

服务会处理用户主动提交的行业、企业规模、角色、业务问题、现有流程、影响和临时附件，用于生成落地地图。会话 Token 仅用于当前匿名会话授权。

## 两类独立授权

- 只有用户明确同意保存并申请人工复核时，地图和企业名称才会进入蓝图 FDE。
- 只有用户另行同意被联系时，联系人、手机或邮箱才会进入蓝图 FDE。

## 保留与删除

匿名会话和临时附件默认最长保留30天（以部署配置为准），用户可在当前会话中主动删除。用户明确授权转换后形成的 FDE 正式业务数据，遵循 FDE 已有保留、权限和审计规则。

公开隐私说明：`https://fde.lantuzhigou.com/legal/clawhive/privacy`。删除匿名会话使用当前会话 Token 调用 `DELETE /api/public/clawhive/v1/sessions/{id}`。

## 安全提示

请勿提交国家秘密、商业核心机密、个人敏感信息或无权处理的数据。AI 结果仅供业务评估，不构成收益保证；信息不足处应显示为待确认。
