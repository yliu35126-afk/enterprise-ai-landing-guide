# Changelog

## 1.3.1 - 2026-08-24

- ClawHive 入口固定识别来源平台，不接受用户选择来源。
- 外部诊断进入 FDE 后先形成待人工确认线索，不直接创建客户或商机。
- 增加 `TEST_DATA` 验收隔离与待确认结果追踪。

## 1.2.2 - 2026-08-24

- 将授权选择改为清晰的三项文字选项，分别对应人工复核、复核并联系、暂不申请。
- 公开技能页仅保留产品说明，执行规则继续放在内部文件。

## 1.2.0 - 2026-08-19

- 更新生产公网入口为 `https://fde.lantuzhigou.com`，保留可配置 API 根地址。
- 统一公开 Skill、OpenAPI 与客户端版本到 1.2.0。

## 1.0.0 - 2026-08-06

- 首次发布匿名会话、单问题动态追问与企业AI落地地图。
- 提供结构化 JSON、Markdown、临时附件、主动删除与幂等重试。
- 拆分“同意保存”和“同意联系”，实现受控 FDE 人工复核转换。
- 增加 OpenAPI、零依赖 Python 客户端和三个行业样例。
## 1.2.1 - 2026-08-24

- 将公开技能说明收敛为产品语言，执行规则移入内部 references 文件。
