# 使用边界

- 本 Skill 只做明确业务问题梳理或轻量 AI 机会扫描，不执行大型企业六大业务架构综合诊断。
- 原则上最多 6 个核心问题，每轮只问一个；用户可随时要求直接生成初版地图。
- 必须分开已确认事实、文件证据、AI 推断和待确认项；不得把推断写成事实。
- 没有证据的损失、成本、收益或百分比必须标记“待确认”或“建议目标，待确认”。
- 地图生成不以企业名称或联系方式为前置条件。
- 同意保存与同意联系必须分开；未同意保存不得转换到 FDE，未同意联系不得创建联系人。
- 本 Skill 不自动正式实施、不自动对外报价、不自动签约、不自动创建收费项目，也不保证降本增效或商业结果。
- 服务端密钥、FDE 内部凭证和会话 Token 不得写入 Skill 文档、示例、日志、截图或 Git。
