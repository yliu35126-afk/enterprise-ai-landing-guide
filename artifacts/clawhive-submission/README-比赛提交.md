## 作品定位

企业用户只需要输入企业正在做什么、最头疼什么、涉及哪个岗位或流程，也可以补充一段文字或资料。系统会先给出一份轻量、可执行的 AI 落地导航：当前问题、经营影响、最值得先做的场景、AI 与人工的分工、最小验证方式，以及下一步进入蓝图 FDE 的路径。

主流程是：

企业输入问题 → AI 生成导航结果 → 选择最小验证 → 进入蓝图 FDE

它不是大型企业诊断报告，也不代替管理者、工程师或合规人员作最终判断。
